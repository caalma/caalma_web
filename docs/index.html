Probar el pila-web acá

Esta web entiende un lenguaje de pila (RPN): pila-web. Probá estas expresiones:

fondo violeta

fondo original

2 × 3 + 4 = …

Con Alt+Esc abrís el editor y con Alt+Enter evaluás. Alt+U fija el estado en la URL.

Ayuda

  • Alt+Esc editor pila-web · Alt+Enter evaluar · Alt+U fijar URL
  • PIL muestra la pila · AYU lista las palabras
  • ayuda.izquierda.POS cambia la posición de un panel
  • ayuda.80.MAX agranda un panel al 80% de la ventana (ayuda.0.MAX lo restaura); el botón ⤢ de la cabecera alterna el máximo
  • AYU lista todas las palabras; QUE.FOC explica una. elementos.ABR abre un panel para probar EL, YO, FOC y VAL

Probar EL, YO, FOC y VAL

Un campo con una expresión en data-pila-web-input: cada vez que escribís, se evalúa demo-eco.YO.VAL.TXE (YO es el campo, VAL su texto, TXE lo escribe en el elemento demo-eco).

Eco: …

Desde el editor (Alt+Esc) probá demo-campo.EL.PIL o elementos.ABR.demo-campo.FOC, y AYU o QUE.FOC para ver la ayuda.
